## 1. プロジェクト概要

教材「快単」の学習メソッドを忠実にアプリ化し、英単語を短時間で「絶対記憶（見聞きした瞬間に意味が出てくる状態）」にすることを目的とした、**スマートフォン用学習アプリ**である。

- 対応OS：iOS（14以降）／ Android（8.0 / API 23 以降）
- 提供形態：**端末内完結・オフライン動作・サーバ利用なし**
- 収録語数：約 **2,201語**（First stage 見出し語）
- 開発：Flutter によるクロスプラットフォーム開発

MVP版では **First stage** を完成させる。Second stage（2番目以降の意味・派生語・反対語、医系単語、育成キャラクター）は枠のみ用意し、本MVPの対象外とする（「16. 対象外・将来拡張」参照）。

## 2. 用語定義

|用語|定義|
|---|---|
|**満点法（まんてんほう）**|OKした単語を出題から除外し、再チェックした単語のみを次の巡で再出題することを、全単語OKになるまで繰り返す学習方式。本アプリの中核ロジック。|
|**巡目（じゅんめ）**|満点法における出題の周回。1巡目＝最初の出題、2巡目＝1巡目で再チェックした語のみ、…。|
|**ブロック**|2,201語を48語前後ごとに区切った学習単位。全46ブロック。|
|**OK**|意味が分かった単語に対する判定。出題リストから除外される。|
|**再チェック**|意味が分からなかった単語に対する判定。次の巡で再出題される。|
|**初回OKを除く**|各ブロックに最初に取り組んだ際にOKした単語を除外して出題する開始モード。|
|**回転（かいてん）／ラップ**|指定範囲の全単語が全OKになり指定範囲終了に至ること。星評価の単位。|
|**ステージ**|First stage（見出し語の中心的意味）／ Second stage（2番目以降の意味・派生語等）。MVPはFirst stageのみ。|
|**TTS**|💡 Text-to-Speech。端末標準の音声合成機能で英単語を読み上げる仕組み。|

## 4. 画面仕様

各画面について「目的／表示要素／操作／状態／遷移」を定義する。画面番号は解説書の丸数字に準拠する。レイアウトは片手操作・3秒チェックを最優先とし、主要ボタンは親指可動域（画面下部）に配置する。

### 4.1　① スタート画面

|項目|内容|
|---|---|
|目的|学習するステージを選択する起点画面。|
|表示要素|アプリタイトル／ロゴ、`First stage` ボタン（5つの星表示を含む）、`Second stage` ボタン（「準備中」表示・5つの星表示枠）。|
|操作|`First stage` タップ → ② 範囲指定画面へ。`Second stage` タップ → 「準備中」トースト表示（MVPでは遷移しない）。|
|状態|各ステージボタンの下に星5個を表示（「9. 星評価」参照）。|
|遷移|→ ② First stage 範囲指定画面。|

> 💡 Second stageは枠と「準備中」表示のみ用意し、将来の拡張をユーザーに示す（教材販売時のアピールにもなる）。

### 4.2　②③ 範囲指定画面

|項目|内容|
|---|---|
|目的|学習対象のブロックを選択し、開始モードを決めて出題を開始する。|
|表示要素|46ブロックのボタンをグリッド配置（快単vol.1＝ブロック1〜23、vol.2＝ブロック24〜46）。各ブロックに番号と語ID範囲（例：「7：289〜336」）を表示。vol.1全体／vol.2全体の **一括選択ボタン**。`スタート`／`初回OK を除く` の開始ボタン。`リセット` ボタン。|
|操作|・ブロックをタップで選択／選択解除（順不同・複数可）。<br>・一括選択ボタンで該当vol全ブロックを一度に選択。<br>・`リセット`：選択状態と当該範囲の学習記録をクリアし、全ブロックを白に戻す。<br>・`スタート`：選択範囲の**全単語**を出題（前回記録をリセット）。<br>・`初回OK を除く`：各ブロックで初回にOKした単語を除外し、再チェック対象のみ出題。|
|状態（ブロックの色）|**白＝未学習／リセット後**、**青＝選択中**、**薄い色（うす青）＝全OK完了**。完了済み（薄色）ブロックと未学習（白）ブロックを同時選択可能。|
|遷移|`スタート` または `初回OK を除く` → ⑥ 問題画面。|

> **補足：開始モードの動作差**
> - `スタート`：選択範囲の記録を消去し、全単語を1巡目として出題する。
> - `初回OK を除く`：各ブロックに最初に取り組んだ際にOKした単語を出題から除外する。白ブロック（学習履歴なし）にこのモードを適用した場合は、OK=0として全単語が出題される。

### 4.3　⑥ 問題画面

|項目|内容|
|---|---|
|目的|単語を提示し、意味を想起させる。3秒以内の判断を促す。|
|表示要素|・**単語**（大きく表示）<br>・**品詞**（他／自／名／形／副／前／接／間。複数品詞があれば併記）<br>・**問題番号**（見出し№、例：№0341）<br>・ステージ名（First stage）<br>・**スピーカーボタン**（TTS再生）<br>・`意味・例文` ボタン<br>・画面下部の**カウンタ**：`残/総数`・`OK 数`・`再チェック数`（リアルタイム更新）|
|操作|・画面表示時に発音音声を自動再生。<br>・スピーカーボタンで再度再生。<br>・`意味・例文` タップ → ⑦ 解答画面。|
|状態|カウンタは当該巡の進捗をリアルタイム反映。|
|遷移|→ ⑦ 解答画面。|

### 4.4　⑦ 解答画面

|項目|内容|
|---|---|
|目的|意味・覚え方を提示し、OK／再チェックを判定させる。|
|表示要素|・単語、品詞、カタカナ読み<br>・**意味**（意味1・意味2）<br>・**覚え方**（ゴロ／語源／カタカナ／イメージ）<br>・**語源**（源タグの内容、ある場合）<br>・**イラスト**（💡 将来対応。MVPでは枠のみ／非表示）<br>・**例文**（英・日。画面末尾に表示）<br>・`OK` ボタン／`再チェック` ボタン（大きく配置）<br>・画面下部の同カウンタ|
|操作|・`OK`：当該単語を出題リストから除外し、即座に次の単語の⑥問題画面へ。<br>・`再チェック`：当該単語を次巡の再出題リストに残し、即座に次の単語の⑥問題画面へ。<br>・例文を参照してからOK／再チェックを押すことも可能。|
|状態|当該巡の最後の単語に対する判定後は、結果表示画面へ自動遷移（「7. 満点法ロジック」参照）。|
|遷移|→ ⑥ 問題画面（次の単語）／ 当該巡終了時 → ⑧ 結果表示画面。|

> 💡 操作速度を最大化するため、問題⇄解答の往復は**画面遷移アニメーションを最短（100ms以下／実質無し）**とする。

### 4.5　⑧⑩ 結果表示画面

|項目|内容|
|---|---|
|目的|当該巡の結果を提示し、次巡または範囲終了へ導く。|
|表示要素|`今回の結果`：`総数`・`OK 数`・`再チェック数`。`次に進む` ボタン。`範囲再指定` ボタン。|
|操作|・`次に進む`：再チェックした単語のみで次巡を構成し、⑥問題画面へ。<br>・`範囲再指定`：②範囲指定画面へ戻る。|
|状態|当該巡で再チェックが0件（全OK）の場合は、本画面を経由せず（または経由後自動で）⑪指定範囲終了画面へ移行する。|
|遷移|→ ⑥ 問題画面（次巡）／ ⑪ 指定範囲終了画面（全OK時）／ ② 範囲指定画面。|

### 4.6　⑪ 指定範囲終了画面

|項目|内容|
|---|---|
|目的|範囲達成を祝福し、学習状態を確定する。|
|表示要素|「頑張った！おめでとう！」等のメッセージ、**お祝い演出（3〜5秒）**。|
|操作|演出再生後、自動的に①スタート画面へ戻る。|
|状態|・選択していたブロックの色を**完了（薄色）**に変更。<br>・**前回1巡目の再チェック記録は保持**する（「初回OKを除く」用）。<br>・46ブロック全完了時も①スタート画面へ戻る（星評価が1回転分進む。「9. 星評価」参照）。|
|遷移|→ ① スタート画面（自動）。|

> 💡 お祝い演出は、軽量・高画質で実装できる**アニメーション（Rive/Lottie）**を推奨。動画ファイル（mp4）をご支給いただく場合はそれを再生する形にも対応可能（ご確認事項 Q-5）。

## 5. 満点法ロジック詳細（中核）

本アプリの価値を決定する中核ロジック。明確なステートマシン（💡 状態と遷移が定義された処理機構）として実装し、全パターンを検証する。

### 5.1　基本アルゴリズム

```
1. 出題リスト ← 選択範囲の対象単語（モードにより初回OK語を除外）
2. 巡目 ← 1
3. 出題リストをランダム順に並べ、1単語ずつ問題画面に出題
4. 各単語について判定：
     - OK      → 当該単語をリストから除外
     - 再チェック → 「次巡リスト」に追加
5. 当該巡の全単語を出題し終えたら、結果表示画面を表示
6. 次巡リストが空（再チェック0件）→ 指定範囲終了画面へ（学習完了）
   次巡リストが残あり → 出題リスト ← 次巡リスト、巡目+1、3 へ戻る
```

### 5.2　巡目進行の例（解説書④〜⑩：ブロック7+8＝96語）

|巡目|出題数|OK|再チェック|
|:---:|:---:|:---:|:---:|
|1巡目|96|56|40|
|2巡目|40|26|14|
|3巡目|14|10|4|
|4巡目|4|4|0 → **全OK・指定範囲終了**|

### 5.3　検証観点（テスト項目）

- 巡目進行（多巡にわたる除外・再構成の正確性）
- ランダム出題（同一巡内で重複なく全単語が出題されること）
- 全OKでの自動遷移
- アプリ再起動後の巡の途中復帰
- 複数ブロック選択時／白・薄色ブロック混在時の動作
- 「初回OKを除く」適用時の動作

## 6. 「初回OKを除く」仕様

|項目|内容|
|---|---|
|目的|既に習得済み（初回OK）の単語を省き、未習得語に集中して復習効率を高める。|
|定義|各ブロックに**最初に取り組んだ巡（初回）**で `OK` と判定した単語を、次回以降の出題から除外する。|
|データ|単語ごとに「初回判定結果（first_round_result）」を永続化する（ER図 `word_progress` 参照）。|
|白ブロック適用時|学習履歴がないため除外対象なし。OK=0としてブロック内全単語を出題する。|
|保持タイミング|⑪指定範囲終了時、前回1巡目の再チェック記録を保持する（解説書⑨）。|

## 8. 星評価システム仕様（MVP同梱）

|項目|内容|
|---|---|

> 💡 「全ブロック完了＝1回転」の定義の詳細（部分範囲のみの完了を回転に数えるか）はご確認事項 Q-3 参照。

## 9. 学習履歴・データ永続化仕様

端末内データベース（💡 SQLite）に保存し、アプリを閉じても学習状態を完全に維持する。詳細は `03_快単_ER図_v1.0.md` を参照。保存対象は以下のとおり。

- ブロックごとの状態（未学習／完了、完了日時）
- 単語ごとの学習履歴（初回判定、直近結果、試行回数）
- 学習セッション（選択ブロック、現在の巡目、各単語の巡内結果）— **中断・再開に対応**
- ステージごとの回転数（星評価）
- 設定（選択中のステージ等）

> データは2つに分離して管理する：**①単語マスタ（読み取り専用・アプリに同梱）** と **②学習履歴（書き込み可能）**。これにより、将来「英検1級3000語」等の教材を追加する際は単語マスタを差し替えるだけで済み、利用者の学習履歴は影響を受けない（保守性・拡張性のための設計）。

|意味・覚え方・語源・発音記号|製本PDF（アウトライン化）から弊方で抽出|菊地様→弊方抽出|
|覚え方イラスト（2,201枚）|画像ファイル|菊地様（Drive/Dropbox）|
|発音音声|端末TTSを使用（音声ファイル不要）|—|

> **データ品質に関する方針**：製本PDFはテキストがアウトライン化されているため、AIによる画像解析で抽出する。全自動はリスクがあるため、**100語程度のサンプルを菊地様にご確認いただき、精度ご納得後に全件抽出**する工程を設ける。

## 11. 音声仕様

- MVPは**端末TTS**（💡 iOS／Android標準の音声合成）で英単語を読み上げる。音声ファイルは同梱しない（アプリ容量と保守性のため）。
- 問題画面表示時に自動再生。スピーカーボタンで再再生。
- 将来、ご支給の録音音源（例：kai-julie 音声）への差し替えにも対応できるよう、音声機能は内部的に分離して実装する。
